# Support

Use the repository's [GitHub issues](https://github.com/BioDataUniMI/Text2Cypher-hub.github.io/issues) for:

- missing or incorrect registry metadata;
- broken links;
- site bugs and accessibility problems;
- feature requests and questions about contributing.

Questions about a listed dataset should be directed to that dataset's publisher. T2C-Registry does not redistribute or provide support for upstream data.
