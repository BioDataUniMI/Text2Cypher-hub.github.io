# T2C-Hub

**Text2Cypher-Hub** is a platform that collects resources for building, training and evaluating **Text2Cypher** systems, including datasets, benchmarks, tools and reproducibility guidelines.

Text2Cypher-Hub maintains:

- [**T2C-Registry**](registry.md), a catalogue of community-developed datasets and benchmarks
- [Evaluation guidelines](evaluation.md) for syntax and execution-based evaluation
- An [issue template](contribute.md) for proposing new resources

## Build your Text2Cypher system

- [Find training and evaluation data in T2C-Registry](registry.md)
- [Choose recommended evaluation metrics](evaluation.md#recommended-metric-stack)
- [Get help from the community](support.md)
